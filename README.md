## About

I am an independent researcher and software engineer. My strongest work tends to start with an under-structured problem: incomplete records, unclear system logic, fragmented sources, or a question that is not yet measurable. I trace evidence, identify relationships, separate what is known from what is still hypothetical, and turn the problem into a research design, working system, implementation plan, or documented decision.
